# 📄 ResumePro Builder

![React](https://img.shields.io/badge/React-18-blue?logo=react)
![Vite](https://img.shields.io/badge/Vite-5-purple?logo=vite)
![License](https://img.shields.io/badge/License-MIT-yellow)
![Status](https://img.shields.io/badge/Status-Live-brightgreen)

A real-time resume builder with an **ATS validation engine** that scores resume layouts instantly. Exports standard-compliant vector A4 PDFs without layout shifts.

🚀 **Live Demo**: [resumepro-builder.vercel.app](https://resumepro-builder.vercel.app/)

---

## ✨ Features

- ⚡ **Real-time preview** — see changes instantly as you type
- 🎯 **ATS Score Engine** — validates resume layout and scores it (used by 150+ candidates)
- 📄 **PDF Export** — standard A4 vector PDF, no layout shifts
- 🎨 **Multiple Templates** — clean, modern resume layouts
- 💾 **Auto-save** — data persists across sessions

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18 + Vite |
| PDF Export | jsPDF + HTML5 Canvas |
| Styling | CSS Grid + CSS Variables |
| Deployment | Vercel |

## 🚀 Setup

```bash
git clone https://github.com/VIPK-GUPTA1827/resumepro-builder.git

npm install
npm run dev
```
